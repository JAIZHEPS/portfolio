BlinkBuy

An omnichannel retail app, redesigned around the moments where shoppers got stuck.

RoleUI/UX Designer
CompanyInfotact Solutions, with a team of designers
DurationMar–Jun 2026
ToolsFigma
live preview ↘

The problem

Onboarding and checkout had pain points that made shopping harder than it needed to be. Users faced difficulties navigating with cluttered user interfaces.

Process

  1. Research: User research to uncover onboarding and checkout pain points. Created empathy maps and user personas for clear understanding and usability.
  2. Flows: Mapped user journeys and reworked navigation structure.
  3. High-fidelity UI: Polished screens designed with consistent UI components.
  4. Review: As first-time designers, my teammates and I received positive feedback, iterated to make the UI simpler, and conducted UX research to understand where users experienced difficulties.

Key decisions

  • Simpler onboarding: Applied color theory and addressed user pain points, making the login process easier by adding a mobile number option.
  • Streamlined checkout: Simplified navigation and added an intuitive, visually appealing user interface so users can move through the app easily.
  • Clearer navigation: Restructured pathways so users experience seamless navigation throughout the application.

Outcome

High-fidelity screens and streamlined navigation flows.

Carevo

Healthcare made simple: a telemedicine dashboard with a calm, clear hierarchy.

RoleUI/UX Designer
CompanyInfotact Solutions
DurationMar–Jun 2026
ToolsFigma, interactive prototype
live preview ↘

The problem

Healthcare tools can overwhelm people at stressful moments. Carevo needed an interface that makes care easy to find and manage. This web application is targeted towards older and busy individuals.

Process

  1. User flows: Planned the main journeys such as login, main dashboard, booking details, profile, and appointment confirmation.
  2. Visual hierarchy: Decided what shows first and what can wait.
  3. Design system: Reusable components for consistency.
  4. Prototype: Mobile screens and a clickable Figma flow.

Key decisions

  • Hierarchy: Next appointment is the biggest element, alongside the doctor’s information screen.
  • Calm visuals: White and blue were chosen for a calm and effortless user experience, avoiding overly flashy colors that induce tension.
  • Accessibility: Medium to large font sizes to help the targeted users navigate throughout the app more seamlessly.

Outcome

A clear, consistent dashboard with a working interactive prototype.

Health Prediction

A health prediction model that trains across datasets while keeping data private, using federated learning.

RoleDeveloper (ML)
DurationJun–Jul 2025
StackPython, TensorFlow Federated, React
FocusPrivacy-preserving AI
live preview ↘

The problem

Health data is sensitive, so pooling it in one place is risky. The goal was a prediction model that learns from several datasets without centralizing the raw data.

Approach

  1. Data: Trained across multiple distributed datasets including heart, lungs, and thyroid health records.
  2. Federated learning: Models are trained locally on decentralized client nodes and aggregated, keeping raw patient data secure.
  3. Model: Multi-model architecture combining specialized ML predictors into an interactive diagnostic interface.

Technologies used

  • Machine Learning & Federated: Python, TensorFlow Federated (TFF), Scikit-learn, NumPy, Pandas, Matplotlib, Flower framework.
  • Frontend: React.js, JavaScript, HTML5, CSS3.
  • Backend & Database: Node.js, Express.js, MongoDB.
  • Version Control & Testing: Git, GitHub, Postman API Testing.

Related work

I also built an AI health predictor that reads user-entered symptoms and suggests possible conditions using NLP and machine learning.

Outcome

A working privacy-preserving health prediction model with an interactive multi-model health prediction interface.

UNAVU

A minimal mobile food-delivery interface, designed from user flow to interactive prototype.

RoleUI/UX Designer
PlatformMobile app
ToolsFigma
TypePersonal project
live preview ↘

The problem

Food-delivery apps are often crowded with offers, clutter, and endless options. UNAVU explores a simpler, calm way to find food and order without decision fatigue.

Process

  1. User flow mapping: Mapped the core journey from opening the app to discovering meals, customizing items, and completing orders seamlessly.
  2. Wireframing: Sketched and tested clean low-fidelity wireframes focused on uncluttered layouts, intuitive search, and instant cart access.
  3. Interactive prototype: Connected high-fidelity screens into a clickable Figma mobile prototype.

Key decisions

  • Minimal layout: Simple screens and streamlined bottom navigation, keeping the focus entirely on appetizing meals without distracting ads.
  • Type and color: Warm peach and gentle lavender tones paired with clean typography for a comforting, appetizing visual identity.

Outcome

A clean food-delivery prototype you can click through, validating an effortless ordering journey that feels refreshing and frictionless.
